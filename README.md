# 知跃 · Zhiyue 1.1 预览版

知有所向，思有跃迁。

由 **gulinyue** 开发的社区免费桌面助手，支持实时面试系统收音与自动回答、笔试截图出答案、文字问答、本机知识库与会话记录。新增局域网双端互通：手机遥控电脑截图，两端同步看答案，电脑快捷键滚动手机答案页。无需应用账号，直接连接自己的模型服务。

## 安装

Windows 10 2004 或更新版本 / Windows 11，64 位系统。

从 [Releases](https://github.com/Gulinyue/zhiyue/releases) 下载 `Zhiyue-Setup-1.1.0-beta.5-x64.exe` 体验下一版；需要稳定版可继续使用 1.0.1。双击后按中文向导选择安装位置。安装程序为当前用户安装，创建桌面与开始菜单快捷方式，无需另装 Node.js。安装包尚未购买代码签名证书，Windows 可能显示未知发布者。

首次运行需要配置自己的模型连接。发行版使用系统用户数据目录保存设置，不预置开发者的账号、密钥、资料或会话。卸载默认保留用户数据。

软件“连接与设置”顶部提供“爱发电支持开发者”入口，点击后由默认浏览器打开赞助页。Bug 反馈邮箱：[linyue_clawbot001@163.com](mailto:linyue_clawbot001@163.com)。

## 从零开始的新手教程

首次打开可点击工作台“新手教程”，也可从侧栏或设置中的醒目入口进入。教程共 10 步，覆盖 DeepSeek 和阿里云注册、开通服务、创建 Key、复制粘贴、测试保存、真实使用及常见错误排查；进度保存在本机。

示例使用 DeepSeek 的 deepseek-flash 配置文字问答与截图分析、百炼北京的 qwen3-asr-flash 配置语音。可一键预填地址/协议/型号并定位输入框，Key 始终由用户手动粘贴。平台页面以当前实际显示为准，API 额度与费用以平台控制台为准。完整文字版见[新手教程](docs/BEGINNER.md)。

## 实时面试（1.1 预览）

已配对的手机会同步显示面试问题和流式回答，电脑快捷键可滚动手机知跃页面。连接方式见下方“双端互通”。

1. 在“连接与设置”配置文字问答模型，并在语音转写中选择服务商、模型和 API Key。预设支持千问百炼（北京/新加坡）、智谱 GLM-ASR、硅基流动、OpenAI、Groq、Together AI，也可使用本机或自定义兼容接口；可获取模型列表、手动填写 ID，并测试后保存。
2. 点击侧栏“实时面试”或设置中的“开始面试”，即开始系统收音并进入半透明、鼠标穿透的悬浮窗，无需再次点击开始。**仅收录电脑播放的声音，不使用麦克风**。使用 Windows 窗口捕获排除机制。
3. 在“面试定制”点击“应用快速口述推荐”：以应聘者第一人称输出简短口述稿，采用快速模式、0.7 秒停顿和自动回答；已有设置不会自动覆盖。也可选择回答提纲、稳健模式及其他窗口/知识库偏好。关闭自动回答后，按 **Alt+C** 提交当前转写问题。
4. 按 **Ctrl+Shift+Z** 或 **Ctrl+3** 结束收音、转写和生成，并恢复可点击的设置界面。**Ctrl+Shift+H** 隐藏窗口，**Ctrl+Shift+E** 恢复显示，显示后仍保持穿透。会话文本保存在本机；从历史选择继续面试也会启动收音。

快速模式下，长问题每 6 秒提前转写，提问结束后再合并回答；减少历史/资料与输出长度，DeepSeek 关闭深度思考，首段文字立即流式展示。悬浮窗只展示当前问题及最新口述稿，完整记录保存在本机，并显示最近一片转写及回答首字耗时。首字耗时从本次生成开始计算，不含停顿、转写与排队；真实网络和服务商耗时不作固定保证。

原始音频不落盘，短片段仅发送到配置的语音服务；问题及匹配资料发送到回答模型。长问题分段转写、停顿后合并回答。此预览采用分句转写，响应速度由停顿阈值、语音服务和回答模型共同决定。ChatGPT 账号授权不会作为语音服务凭据使用。详见[实时面试说明](docs/INTERVIEW.md)。

## 笔试模式

1. 在“连接与设置”配置截图模型，并在“笔试定制”选择知识库、编程语言、回答语言和提示词；顶部“快捷键提示栏”区域可直接选择“显示提示栏”或“隐藏提示栏”，默认显示。
2. 点击“笔试模式”或“开始笔试”，立即打开默认 52% 不透明度、鼠标穿透且不可点击的悬浮窗。
3. 打开题目，按 **Ctrl+Q** 截图，自动识题并生成答案，无需另点发送；长题按 **Ctrl+Shift+Q**。
4. 按 **Ctrl+Shift+Z** 退出笔试，恢复可点击的设置界面。退出会停止模型生成并丢弃迟到截图。

支持选择题、简答题、编程题；先给答案，再给必要解析，编程题包含代码和复杂度。新截图独立解题，文字追问继续当前上下文；模糊题干会要求补充。答案和笔试模式会保存在本机，可从会话记录继续。按键可在设置中修改。

## 双端互通（beta.5）

1. 电脑和手机接同一私人 Wi-Fi 或热点，在电脑“连接与设置 → 双端互通”选择网卡，点击“开启局域网互通”。
2. 手机相机扫码，用浏览器打开；填写设备名并申请配对，再在电脑核对后点击“允许配对”。也可手动输入地址及 8 位配对码。
3. 手机点击“截图并解题”，电脑自动进入笔试模式并截图；文字、笔试和实时面试回答会流式同步。手机可控制电脑答案滚动、窗口显隐和退出模式。
4. 电脑按 **Ctrl+↑ / Ctrl+↓** 滚动手机答案页，设置中也提供按钮。手机可调整字号、手动滚动或跟随最新回答，断线后自动重连。

服务默认关闭，无需云端中转或手机安装。关闭互通或退出软件后重新配对；锁屏时暂停并清空手机答案。只在可信私人网络使用，当前为局域网 HTTP；手机不接收模型密钥、截图原图或知识库原文。详见[双端互通教程与数据说明](docs/LAN.md)。

## 模型连接

预设覆盖 OpenAI、Claude、Gemini、Azure、Grok、DeepSeek、Mistral、Groq、OpenRouter、通义千问、硅基流动、Kimi、GLM、Together、Fireworks、Perplexity，以及本机 Ollama / LM Studio。支持自定义 Base URL、模型 ID、模型列表发现和四种推理协议。

可通过 **Continue with ChatGPT** 在浏览器中授权自己的账号，使用符合账号权限的 ChatGPT 套餐模型。ChatGPT 授权是面向个人本地使用的预览集成；闭源社区版本公开分发前需另行确认产品的接入资格。应用本身免费，外部模型服务可能收费，额度和权限以服务商为准。使用本机模型需要自行运行对应服务。

## 悬浮窗与快捷键

普通“专注窗口”支持置顶、1%–100% 不透明度、拖动缩放和鼠标穿透。笔试模式自动进入不可点击浮层，使用独立的 15%–85% 不透明度设置。Windows 主窗口与快捷键提示浮层均启用并读回验证 WDA_EXCLUDEFROMCAPTURE；退出快捷键未注册或捕获排除不可用时，不进入笔试模式。

| 操作 | 默认快捷键 |
| --- | --- |
| 截图并直接出答案 | Ctrl+Q（笔试模式 / 专注窗口） |
| 滚动截图并直接出答案 | Ctrl+Shift+Q |
| 移动窗口 | Ctrl+Shift+方向键 |
| 上下滚动回答 | Ctrl+Win+↑ / ↓ |
| 上下滚动已配对手机的答案页 | Ctrl+↑ / ↓ |
| 横向滚动代码 / 表格 | Ctrl+Alt+Shift+← / → |
| 隐藏 | Ctrl+Shift+H |
| 显示窗口（笔试中保持穿透） | Ctrl+Shift+E |
| 退出笔试并恢复操作 | Ctrl+Shift+Z |
| 调整不透明度 | Ctrl+Shift+[ / ] |
| 普通专注窗口穿透切换（笔试中锁定） | Ctrl+Shift+X |

## 本地运行与构建安装包

需要 Node.js 22 或更新版本。已安装依赖时运行：

```powershell
npm.cmd start
npm.cmd run dist:win
```

新环境先执行 `npm.cmd ci`。安装包输出到 `dist/`，通过 electron-builder / NSIS 生成。开发数据保存在 `.runtime/local-dev/`。密钥及账号令牌使用操作系统安全存储加密，资料与文字会话保存在本机；原始截图不写入会话 JSON，可选择单独归档。渲染进程禁用网络连接，模型请求通过受限 IPC 在主进程中发送。打包只收录编译产物、运行依赖和许可文件，不收录开发数据及源码映射。

## 验证

```powershell
npm.cmd run verify          # 源码检查、73 项测试、构建
npm.cmd run test:smoke      # 实际 Electron：笔试截图直答、窗口与模型链路
npm.cmd run test:auth-smoke # 实际 Electron：模拟 OAuth、签名校验、加密存储
npm.cmd run test:interview-smoke # 实际 AudioWorklet：合成音频到自动回答与取消
npm.cmd run test:lan-smoke  # 实际 Electron + 手机尺寸浏览器：配对、同步与双向控制
npm.cmd run test:guide-smoke # 新手教程和预填配置
npm.cmd run assets:logo     # 从矢量母版重建 PNG / ICO
```

模型服务、OAuth 服务和截图图像在冒烟测试中使用模拟数据；不访问真实账号或付费模型。实时面试使用真实 AudioWorklet 与合成音频验证分句、转写请求、连续回答、配对端同步、取消和停止后丢弃结果；尚需在真实系统音频设备与用户的语音服务上体验识别准确率和时延。双端互通通过真实 HTTP 与独立沙箱中的手机尺寸浏览器验证，尚需真实 Android / iPhone 和不同路由器体验验收。Windows 原生样式和显示亲和性通过实际 User32 读取验证；未对每一种会议软件进行录屏验收。捕获排除只覆盖支持该机制的系统路径，不保证阻止所有录制方式。
