# 双端互通 · 1.1.0-beta.5

知跃支持 Windows 电脑与手机浏览器在同一局域网配对。无需手机 App，无需云端中转。开发者：gulinyue。

## 第一次连接

1. 电脑和手机连接同一个私人 Wi-Fi，或让电脑连接手机热点。电脑先启动知跃，配置好截图分析模型；需要面试回答时，另配置文字与语音模型。
2. 打开电脑“连接与设置”，找到顶部的“双端互通”。选择与手机同网的网卡地址，点击“开启局域网互通”。默认不会开启，也不会随启动自动开放端口。
3. 若 Windows 弹出网络权限提示，按需允许“专用网络”。知跃不自动修改防火墙规则。
4. 手机用系统相机扫描二维码，选择浏览器打开。也可以手动输入电脑显示的完整地址（包含 http:// 和端口），填写 8 位配对码。二维码带有临时配对码，打开后会从地址栏移除。
5. 手机填写一个容易辨认的设备名，点击“申请配对”。回到电脑核对设备名和地址，点击“允许配对”。未经电脑允许，手机不能看答案或控制电脑。
6. 手机显示“双端已连接”后，点击“截图并解题”。电脑自动进入笔试悬浮窗，截图并提交给配置的截图模型；回答边生成边显示在两端。

配对码两分钟内有效，申请一分钟内有效。过期后在电脑刷新配对码并重新申请；已批准的连接不因刷新配对码而断开。最多配对四台设备。配对只保存在内存中，八小时后失效；关闭互通或退出知跃后，所有手机都需重新配对。

## 两端控制

| 操作端 | 操作 |
| --- | --- |
| 手机 | 截图并解题；上下滚动电脑答案；显示或隐藏电脑窗口；退出当前笔试或面试模式 |
| 电脑 | Ctrl+↑ / Ctrl+↓ 滚动手机里的知跃答案页面；设置中也有“手机答案 ↑ / ↓”按钮 |
| 手机本地 | 手动滚动、字号 A− / A+、跟随最新回答、断开配对 |

快捷键可在电脑“悬浮窗快捷键”修改；仅在有手机连接且电脑未锁定时注册手机滚动键。它们控制知跃网页，不控制手机的其他 App。

电脑截图使用所选显示器。手机触发截图会沿用笔试模式的半透明、穿透及 Windows 捕获排除保护；截图模型未配置、电脑正在处理任务或正在实时面试时，会提示稍后重试或先退出面试。手机退出模式后，电脑恢复可操作的设置界面。显示窗口不会解除笔试/面试的穿透保护。

文字问答、笔试和实时面试的回答均会同步。手机显示当前会话最近六条问答文本，保留 Markdown、代码和公式；每条最多十二万字符，总计最多二十四万字符，优先保留最新回答。完整会话保存在电脑。电脑切换设置时仍可接收正在生成的答案。手机手动滚动或收到电脑滚动指令后停止跟随；点击“跟随最新”恢复。

## 断线和常见问题

- 手机息屏或浏览器切到后台时，系统可能挂起网页。返回前台会自动重连并获取最新答案，也可点“立即重连”。保持同一浏览器标签页可在会话内刷新恢复。
- 电脑锁屏或休眠时，手机答案清空、远控暂停；解锁后重新同步。电脑退出知跃或撤销配对时，手机清除本次会话凭据。
- 打不开页面：检查同网、专用网络防火墙权限、完整端口和网卡选择。访客 Wi-Fi、公司网络的设备隔离、VPN 或热点策略可能阻止设备互访。
- 微信内无法打开时，改用 Safari / Chrome。无需麦克风、相机或手机辅助功能权限。
- 手机网络地址改变、Wi-Fi 切换或热点重连后，原凭据可能失效；请重新配对。电脑换网后，先关闭互通，再选新地址开启。
- 无法注册手机滚动键时，检查是否被其他软件占用，并在设置更换组合键。

## 数据边界

只在可信的私人网络开启。此版本使用局域网 HTTP，没有传输加密；同网设备可能监听文本和连接凭据，不适合公共 Wi-Fi，也不要配置公网端口转发。

服务只绑定选定的私人 IPv4 地址和临时端口。浏览器请求校验 Host、来源和配对令牌，拒绝跨站调用；令牌不放入网址、不写入电脑磁盘，并绑定手机当前地址。支持电脑确认、限速、撤销和锁屏暂停。手机只保存当前标签页的临时凭据。

模型密钥、账号令牌、知识库原文及截图原图不会通过互通通道发送到手机。原图仍会按用户配置发送到截图模型；匹配的知识片段仍可能随问题发送到回答模型。最终模型回答和用户问题会作为可见文本同步到已批准的手机。手机网页没有 Electron IPC 权限。

## 已验证范围

自动测试覆盖真实 HTTP 配对、错误来源拒绝、超时、撤销、锁屏、重连、流式回答和双向控制。Electron 测试使用独立沙箱中的 390px 浏览器模拟手机，截图与模型为模拟数据；实时面试另以合成系统音验证向配对端同步。尚未在真实 Android / iPhone、不同路由器或实际付费模型上完成双端体验验收。
