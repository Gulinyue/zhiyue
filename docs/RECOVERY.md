# 恢复记录

> 以下记录描述恢复版基线，对应 `codex/cloud-recovered` 分支。本地独立版的修改与验证见 [LOCAL.md](LOCAL.md)。

## 输入与恢复方式

提供的文件不只有技术文档，还包括 `out/main/index.js`、预加载脚本、约 2.7 MB 的可读界面构建代码、样式和静态资源。多个文件都被插入了约三个前缀字节，同时截去了末尾字节，附带的依赖文件也有同类损坏。

保留原始副本后，修复了以下边界：

| 文件 | 修复 |
| --- | --- |
| `package.json` | 移除异物前缀，重建有效清单和构建脚本 |
| 主进程 | 从 `"use strict"` 开始恢复，补回最后的分支闭括号 |
| preload | 移除前缀，补回 `exposeInMainWorld` 调用结尾 |
| renderer JS | 从首个有效声明开始恢复，补回根组件 render 调用结尾 |
| HTML | 移除 doctype 之前的异物，补全闭合标签，修复 CSP 所在位置 |
| CSS | 移除前缀，补全最后一个规则，修复字体引用 |
| 图标 PNG | 去掉三字节前缀，补回已知 PNG IEND 尾部；逐块验证 CRC |
| KaTeX 字体 | 损坏的二进制尾部无法猜测；从相同版本 0.16.22 的发布包恢复字体，并保留其许可证 |

不是把编译产物直接当作最终输出运行：按完整顶层声明拆出 ES Modules，使用词法作用域分析生成依赖，拒绝跨模块变量写入。主进程、预加载和渲染层由 esbuild 从 `src/` 重建，IPC 通道由同一模块提供。

原始 JSX 表达式、类型注解和原文件名没有可靠证据可恢复。没有伪造它们，也没有创建一个假后端替代真实服务。本地 HTTP 模拟器只用于测试。

## 相比原产物的明确改动

1. 登录令牌不再回退为可逆的明文 Base64；系统加密不可用时保存失败。保存 access/refresh token 前先完成所有加密，避免部分提交。
2. 网页门户只允许配置的确切 origin，拒绝任意协议、伪装域名和 URL 内嵌凭据。
3. 全部特权 IPC 统一校验主窗口与顶层 frame。快捷键浮层仅能读取显示设置和报告布局；不能读取凭据、改设置或执行其他特权调用。
4. 禁止渲染器自行打开新窗口、导航外部页面和挂载 webview；网页入口通过受限 IPC 打开。
5. 安装包下载必须匹配维护在源码中的可信 SHA-256。没有可信摘要时走官网下载页回退，不以文件魔数冒充完整性验证。
6. 修复托盘缺少 ICO 文件的问题，改为使用已经验证的原版 PNG 图标创建托盘图像。
7. 补上公式字体的 `font-src 'self' data:` CSP，保证公式内嵌字体能够加载。
8. 后端与门户 URL 可配置，主进程个人模型授权校验也使用同一后端配置。
9. 移除 preload 中三个没有主进程 handler、且界面未使用的遗留方法。实际登录、退出和订阅刷新仍使用原有 renderer HTTP 流程。
10. 删除未使用的 electron-updater 依赖，重新安装必要依赖，保留锁文件。

## 验证证据

`npm.cmd run verify` 执行所有源码检查、21 项核心测试及完整构建。`npm.cmd run test:smoke` 运行真正的 Electron，并生成：

- `artifacts/login.png`：恢复后的登录界面。
- `artifacts/dashboard.png`：通过本地模拟账号进入的原版工作台。
- `artifacts/smoke-report.json`：检查结果和本地接口路径，不含真实凭据。

冒烟检查包括登录表单提交、token 加密保存、设置回读、知识库账号隔离、个人模型凭据写入/回读/删除、非法门户拒绝、任务面的过期令牌拒绝和有效令牌提交、浮层可见性与权限边界，以及 Windows 主窗和浮层的原生保护读回。

截图没有替代真实云端测试。没有进行真实登录、购买、真实面试监听、远控配对或向云端发送截图。未运行 50 次真实桌面截图压力测试，也未在 OBS、会议软件或 macOS 上验收保护效果。

## 可继续维护的地方

- `src/main/index.mjs` 保留窗口、热键、IPC 之间的原编排，以便逐项对照原行为。
- `src/renderer/services/task-runtime.mjs` 仍是较大的兼容模块，后续可按远控、音频、用量、演练 API 继续拆分。
- 前端 vendor 快照保留原版打包代码和许可证注释；升级 React、Markdown 或 KaTeX 时需要做界面回归。
- 发布安装器还需补充正式签名身份、发布渠道和可信更新摘要；本次交付是可构建和运行的源码工程。
