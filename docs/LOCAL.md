# 知跃本机架构

开发者：gulinyue。社区免费使用，许可见 LICENSE。

## 请求路径

本机界面 → 主进程 IPC 权限与参数检查 → 操作系统加密的用户模型凭据 → 用户选择的模型服务 → SSE 流式回答 → 本机文字会话。

应用无需自己的云端账号服务。模型可为在线服务，也可为已经运行的本机服务。用户可主动通过官方 OAuth 授权 ChatGPT 套餐。

## 本机存储

- local-workspace.json：最多 100 份会话，每份最多 200 条文字消息，总量上限 32 MiB；不写入密钥或原始截图。
- knowledge-libraries-v3/：最多 10 份本机文本资料；按关键词挑选片段供当前问题参考。
- personal-model-credentials.json：操作系统加密的模型 Key。
- personal-model-profiles.json：文字与截图用途的连接、服务商和协议元数据。
- chatgpt-authorization.json：操作系统加密的账号注册信息与当前令牌。
- records-v1/：可选截图归档。

开发运行使用 .runtime/local-dev/。支持 ZHIYUE_USER_DATA_DIR 设置独立数据目录，并兼容既有数据目录环境变量，避免升级后丢失配置。内部文件所有者命名空间不用于网络认证。

## 笔试模式

持久化模式值为 written。主进程统一进入笔试窗口模式：先检查退出键注册，隐藏窗口后切换悬浮尺寸、禁用鼠标交互与激活、设置半透明，在 Windows 上验证 WDA_EXCLUDEFROMCAPTURE，再等待界面绘制提交后显示。笔试期普通显示与穿透切换不能解锁窗口。Ctrl+Shift+Z 退出时先隐藏窗口，清理本次生成，再还原普通模式与捕获策略。截图自动提交给截图模型，使用按题号组织、答案优先的专用提示词。新截图不带上题问答，文字追问保留最近上下文。连续快速按键通过截图租约防止重复提交。

## 数据与交互

渲染进程的 CSP 禁止直接网络访问，主进程负责模型、凭据和原生截图。Windows 快捷键提示在主悬浮窗内绘制，共用其原生窗口的捕获排除、穿透和显隐状态；其他平台保留辅助提示窗，不能访问会话或模型凭据。截图支持显示器选择、滚动收集、取消和超时资源清理。内容向上滚动后停止自动跟随，滚回底部或发送新问题后继续跟随。

## 验证

现有单元测试及 Electron 冒烟脚本覆盖模型协议、OAuth、存储、截图调度、笔试截图直答、历史重开、窗口快捷键、不透明度像素、拖动缩放、教程、实时面试、局域网双端互通及 Windows 提示区域捕获像素。捕获测试使用自建纯色窗口和正负对照，验证 GDI 与 Electron 桌面捕获中的背景像素；未自动化 Windows 截图工具界面。外部服务与截图图像使用模拟数据，音频由本机合成，不登录用户真实账号。双端测试采用独立沙箱中的手机尺寸浏览器，未代替真机验收。详见 MODELS-WINDOW.md、INTERVIEW.md 和 LAN.md。

## 局域网互通

主进程提供默认关闭的 HTTP 服务，绑定用户选择的私人 IPv4 网卡。内存保存两分钟配对码、待确认申请和八小时设备会话；电脑确认后才签发随机令牌，校验来源、Host、设备地址和限速。锁屏清空同步内容并拒绝远控，关闭或退出清空会话。手机网页采用独立 CSP，无 Electron IPC；截图命令通过主界面确认可执行后，进入原有笔试和截图链路。

电脑渲染器经受限 IPC 发布最近六条文本的有界快照，主进程过滤所有其他字段后用 SSE 推送。70ms 节流保留生成过程的最新文本，重连发送当前完整快照。手机滚动使用一次性事件；不回放旧滚动命令。模型密钥、截图及知识库原文不经过此通道。HTTP 无传输加密，只适用于可信私人网络，使用方法见 LAN.md。


笔试定制保存于 config.json 的 writtenOptions，包含 opacity、codingLanguage、answerLanguage、prompt、knowledgeMode 和 documentIds。截图缺少本地识题文本时附加所选资料的限长片段，文字问题按关键词检索；禁用和未选资料不发送。主窗口保护状态定期检查，界面提交失败时清除笔试锁定并保留可恢复的普通窗口状态。

## 简历与求职

career-workspace.json 独立保存简历、偏好与最多 1000 个职位，总量不超过 32 MiB。简历仅在启用的面试请求中检索，联系方式遮蔽后发送到用户的模型服务；求职材料生成使用已保存简历和职位描述。招聘网站在各自 persist:zhiyue-recruitment-* 会话运行，没有 preload、Node 或主窗口 IPC 权限，不读取密码或导出 cookies。只采集网页当前可见职位，并在用户确认具体批次后按官网按钮操作。

新增 career 集成脚本使用拦截的合成网站、合成简历和合成音频，验证六站 DOM 流程、文档导入/导出及真实面试链路的简历引用。没有代替真实网站和真实账号验收。运行旧版时会占用默认快捷键；career 测试用独立退出键，不修改正常用户数据。详见 CAREER.md。
